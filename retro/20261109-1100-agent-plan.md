## 2. Changes by file

### 2.1 Schemas and validate.py (do first; cheap, catches A40-1)
- `schemas/expected.schema.json`: add the same task_id `pattern` as task.schema.json.
- `validate.py`: when validating `<id>.expected.json`, also validate the sibling `<id>.task.json` if present and fail if
  their task_id differ.
- `schemas/write.schema.json`: add optional `result_source` enum `returned|file|inferred` (A36) so retro can count
  inferred results.

### 2.2 Tools
- `tools/lsp_collide.py` (A42): per defun, flag case-duplicate names across parameters + locals + setq targets
  (e.g. `ne`/`nE`); keep the global defun-vs-setq check.
- `tools/lsp_lint.py`:
  - W5 (A36): a `c:` defun whose last form is `(princ)` or `(princ <x>)` with no returned string -> "return the result string".
  - W6 (A31): `(setq x (or ...))` where x is later used as a value -> "or returns T; use cond".
  - W7 (A43, heuristic): `vlax-ename->vla-object`, `entget`, `entmod`, `ssadd` called with a variable last set from
    `(entget ...)` or `(swl:ent ...)`.
  - Tests in `tools/tests/` with the M18-R3-T15.v1, M18-COS-T4.v1, M18-R3-T9.v3 failure snippets.
- `tools/lsp_dryrun.py` (A44): `--from-live <dwg>` copies the CURRENT L: drawing (read-only copy into swarm/scratch) instead
  of the pre-run backup, so edit-of-prior-task scripts can reach their real PLAN headless.
- `tools/merge_ops.py` (A48): merge `manifests/*.attemptN.ops.json` into the main log, idempotent, sorted by time.
- `tools/visual_crop.py` (A45): apply `page.rotation_matrix` when cropping by text/word boxes; add `--find "<text>"` to
  crop around a found string.
- `tools/acad_dsd.py` (A41/A46): multi-sheet mode `--sheets "<dwg>|<layout>;..."` -> one PDF; used by publish-set tasks.

### 2.3 Shared library `library/acad/swarm_lib.lsp` (+ test)
- `swl:mtext-bottom` (A34): bbox top - max(bbox h, DXF 43); the only allowed MText bottom measure.
- `swl:inside-vp-tol vp box tol` (A33): containment with a tolerance (default 0.10 in), used for unchanged geometry.
- `swl:group-box handles` (A32): one box for a note group, used by both PLAN and CHECK.
- `swl:clash-ex ... exclude-layers` (A35): FRAME excluded only for edges placed ON a border; new text still sees FRAME.
- `swl:result str` (A36): writes `<task>.result.txt` AND returns str - every c: command ends with it.
- `swl:floating-vps layout` (A39/A50): list floating viewports; `swl:on-sheet-p ms-box` true if any shows the box.
