The demand factor, defined as the
maximum peak load in a given time
period divided by the maximum
possible load, decreases as the
number of fixture units (F.U.)
increases, and it reaches 5.265%
at 25640 fixture units. In fact, if all
the 25640 fixtures were operating
simultaneously, the flow would be
2560F.U.X2gpm/fixture =51280
gpm. Instead it is 2700 gpm. This
means that the demand factor has
dropped to 2700/51280=0.05265
or 5.265%. This demand factor can
be applied when the number of
fixture units is in excess of 25640.
For example, 30000 fixture units
would be 30000F.U. X 2gpm/F.U. X
0.05265=3159gpm.
