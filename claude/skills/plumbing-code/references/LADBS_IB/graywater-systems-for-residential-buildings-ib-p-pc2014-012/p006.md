Estimate Graywater flow per occupant:
Any combination of lavatory, shower or bath: 25 gallons per day per occupant
Laundry (Washing machine or wash basin): 15 gallons/ day per occupant
Daily graywater flow example: (4 occupants x 25 gals/day) + (4occupants x 15 gals/day) = 160 Gallons per day.
