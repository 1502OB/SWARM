APPENDIX G
Table 510.1.2(4) is used where sizing a single-wall vent connector attached
to a tile-lined masonry chimney.
Notes:
1. A is the equivalent cross-sectional area of the tile liner.
2. The appliance is permitted to be either Category I draft hood-equipped or
fan-assisted type.
