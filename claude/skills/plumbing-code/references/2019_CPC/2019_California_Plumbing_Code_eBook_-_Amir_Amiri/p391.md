1701.2 Standards, Publications, Practices, and
Guides. The standards, publications, practices, and guides
listed in Table 1701.2 are not referenced in other sections of
this code. The application of the referenced standards, publi-
cations, practices, and guides shall be as specified in Section
301.2.2. The promulgating agency acronyms are found at the
end of the tables.
