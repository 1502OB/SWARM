D 102.0 Sizing by Flow Rate.
D 102.1 General. Storm drainage systems shall be permitted
to be sized by storm water flow rates, using the gallons per
minute per square foot [(L/s)/m2] of rainfall listed in Table D
101.1 for the local area. Multiplying the listed gallons per
minute per square foot [(L/s)/m2] by the roof area being drained
(in square feet) (m2) by each inlet produces the gallons per
minute (gpm) (L/s) of required flow for sizing each drain inlet.
The flow rates shall be permitted to be added to determine the
flows in each of the drainage systems. Required pipe sizes for
various flow rates are listed in Table ll 03.1 and Table 1103.2.
