Format of the Matrix Adoption Tables
The matrix adoption tables, examples of which follow, arc non-regulatory aids intended to show the user which state
agencies have adopted and/or amended given sections of model code. An agency’s statutory authority for certain
occupancies or building applications determines which chapter or section may be adopted, repealed, amended or added. Sec
Chapter 1, Division 1, Sections 1.2.0 through 1.14.0, for agency authority, building application and enforcement
responsibilities.
