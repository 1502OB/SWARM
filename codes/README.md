# Code reference excerpts for code-reviewer

**Moved (2026-11-05):** code text now lives in the `plumbing-code` skill
(`~/.claude/skills/plumbing-code/`): page-indexed extracts per edition under `references/<edition>/`,
the check rubric in `references/rubric.md`, and the indexer `scripts/code_index.py` to add a PDF. Put new code PDFs
through that script instead of copying excerpts here. The notes below are kept for history.

code-reviewer cites code sections. Anything it cites from memory is marked `"citation_basis": "recalled"`
and must be confirmed before it goes to a city. Put verified excerpts here so it can cite them as `"reference"`.

Layout: one folder per edition, e.g.

    codes/2019_CPC_2020_LAPC/   (22-001 Olympic and other 2020-cycle LA jobs)
    codes/2022_CPC/
    codes/2025_CPC/

Useful excerpts (PDF pages or text): water pipe sizing tables (incl. Appendix A), drainage DFU and drain/vent
sizing tables, storm drain tables and the rainfall map/table, gas pipe sizing tables used, cleanout and vent-
terminal sections, water heater sections, local amendments (e.g. LAPC). Name files by section/table,
e.g. `Table_610.4.pdf`, `Table_702.1.txt`.

The review brief's "Code basis" section tells the reviewer which folder and files to read.
